# motion_parallel

## Objective
Create one of those aesthetic real-time hand/finger trackers from my webcam so I can make parallelograms with my fingers and look cool.


## Roadmap

Create a model that can recognize my face, hands and fingers.

Create app frontend and backend to take live images from my webcam and display them to me.

Scrape images to feed them directly into live model running on some container perhaps.

Create first parallelogram with thumbs and pointers.

Create layered parallelograms to make even cooler shapes and aesthetics.
